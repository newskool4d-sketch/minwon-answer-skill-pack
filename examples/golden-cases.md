# 완성 답변 골든 예시

가상 사안 기반의 완성 예시 4건이다. 문체, 결론 우선 구조, 내부 검토표와 대민 발송본의 분리 방식을 참고용으로 보여준다. 실제 기관명, 인명, 사건은 모두 허구이며 개인정보를 포함하지 않는다.

> 가상으로 정한 판단·값에는 `(가상값)`을 붙인다. 표시가 없는 내부 표의 "확인 완료"와 인용 검증표의 상태·확인일도 `(가상값)`으로 본다. 실제로 조회해 채운 칸만 그렇다고 따로 적었다. 이 표시는 스킬의 `[가정: …]`·`[확인 필요: …]` 태그와 다르며, 발송본 예시가 딸린 사례의 내부 표에는 미해소 태그를 남기지 않는다. 각 사례의 발송본 예시는 내부 표의 확인이 모두 끝났다고 가정한 모습이다. 실제 답변에서는 각 칸을 새로 확인해 채우고 예시의 값을 옮겨 쓰지 않는다.

## 사례 1: 수용 가능 (일반민원)

### 민원 요지

- 민원 유형: 일반민원 — 질의민원(처리 상태 확인), 보조로 건의민원(안내 절차 개선) (가상값)
- 신청 취지: 교육원 체험학습 프로그램 신청 결과 안내 문자가 오지 않아 신청 처리 여부 확인을 요청
- 요구사항: 신청 처리 상태 확인 및 안내 절차 개선

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 프로그램 운영 부서 |
| 이송/다부처/협조 | 불필요 | 단일 부서 처리 |
| 처리기간 | 접수일부터 7일 (제도·절차 질의 성격) | 시스템 기한 확인 완료 |
| 법령근거 | 불필요 (사실 확인·안내 사안) | |
| 개인정보 | 신청자 본인 확인 후 본인 신청 건만 안내 | 제3자 정보 미포함 |

### 발송본 예시 (가상값 — 내부 표의 확인 완료를 가정)

귀하께서 신청하신 체험학습 프로그램의 처리 상태 확인을 요청하신 민원에 대하여 다음과 같이 안내드립니다.

확인 결과, 귀하의 신청은 정상적으로 접수되어 참가 확정 처리되었습니다. 다만 안내 문자 발송 과정에서 시스템 오류로 일부 신청자에게 문자가 발송되지 않은 사실을 확인하였습니다.

이에 우리 기관은 미발송 대상자에게 안내 문자를 재발송하였으며, 동일한 사례가 재발하지 않도록 발송 결과 확인 절차를 보완하였습니다.

불편을 드려 죄송하며, 추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

## 사례 2: 수용 곤란 (일반민원)

### 민원 요지

- 민원 유형: 일반민원 — 기타민원(대관 요청). 규칙이 정한 사용허가 신청(법정민원)은 아님 (가상값)
- 신청 취지: 교육원 시설(강당)을 외부 사적 행사 용도로 대관 요청
- 요구사항: 주말 사적 행사 목적 대관 승인

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 시설 관리 부서 |
| 법령근거 | 「○○교육원 시설 사용 규칙」 제○조 확인 (가상값) | 사용 허가 범위: 교육·공공 목적, 규칙이 정한 사용 신청서 제출 필요 |
| 거부 여부·구제절차 | 거부 — 거부 이유와 구제절차 통지 필요 (민원처리법 제27조제3항) | 다툴 여지: 사용허가 신청권을 주는 규칙이 있음 → 담당자·법무 검토 결과, 규칙이 정한 사용 신청서가 제출되지 않아 사용허가 처분에 이르지 않은 것으로 판단 (가상값). 이의신청·행정심판 문구 대신 재검토 요청 경로와 정식 신청 경로 안내. 재검토 접수 부서 ○○부서 확인 (가상값) |
| 개인정보 | 미포함 | |
| 유의점 | 불가 사유를 규정 근거 중심으로 설명, 대안 안내 포함 | |

### 인용 검증표 (내부, 가상값)

| 법령·조문 | 출처(URL 또는 문서 식별정보) | 적용 버전(시행일) | 적용 기준일·선택 이유 | 확인 방법 | 확인일 | 상태 | 사안 적용 판단 |
|---|---|---|---|---|---|---|---|
| ○○교육원 시설 사용 규칙 제○조 | 기관 규칙집, 규칙 번호 ○○ (가상값) | 20XX-XX-XX | 답변일 — 신청 전 안내이므로 안내 시점 시행 규칙 (가상값) | 수기(확인자: 담당자) | 20XX-XX-XX | ✅ 검증 | 적용: 사적 행사는 사용 허가 대상 아님 |

### 발송본 예시 (가상값 — 내부 표의 확인 완료를 가정)

귀하께서 요청하신 우리 기관 강당 대관에 대하여 다음과 같이 안내드립니다.

검토 결과, 요청하신 사적 행사 목적의 대관은 승인이 어려움을 알려드립니다.

우리 기관 시설은 「○○교육원 시설 사용 규칙」 제○조에 따라 교육 목적의 행사 및 공공 목적 활동에 한하여 사용 허가가 가능하며, 사적 행사는 사용 허가 대상에 포함되지 않습니다.

다만, 교육 목적 행사로 대관을 희망하시는 경우에는 사용 신청서를 행사 ○일 전까지 제출하시면 심사 후 안내드리겠습니다.

이번 안내에 대하여 다시 검토를 원하시면 행사의 성격을 확인할 수 있는 자료를 ○○부서로 제출하여 주시기 바랍니다. 확인 후 다시 안내드리겠습니다. 정식으로 사용 신청을 하시는 경우에는 그 처리 결과를 알려드릴 때 불복 방법을 함께 안내드리겠습니다.

자세한 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 문의하여 주시기 바랍니다.

### 사례 2 참고

- 거부 답변이므로 거부 이유와 구제절차를 함께 안내한다. 이 사례는 규칙이 정한 사용 신청서가 제출되지 않아 처분에 이르지 않았다는 가상 검토 결과를 전제로 하므로, 이의신청·행정심판 문구를 붙이지 않고 실제로 이용할 수 있는 재검토 경로를 안내했다. 접수 경로(예: 국민신문고)만으로 처분성을 정하지 않는다.
- 같은 내용이라도 정식 사용허가 신청을 불허하는 처분이라면 행정심판·행정소송 등 불복 가능 여부, 청구절차, 청구기간을 알려야 한다(행정절차법 제26조, 행정심판법 제58조). 처분성을 다툴 여지가 있으면 담당자·법무 검토로 정한다(`core/response-rules.md` 「거부 답변의 구제절차」).

## 사례 3: 이송 (타 기관 소관)

### 민원 요지

- 민원 유형: 일반민원 — 기타민원(시설 설치 요청) (가상값)
- 신청 취지: 교육원 인근 도로의 통학 안전 시설(과속방지턱) 설치 요청
- 요구사항: 과속방지턱 설치

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 타 기관 소관 (도로 관리청) | 도로 시설물 설치 권한 없음 |
| 이송 필요 | 필요 — 관할 지방자치단체로 이송 | 이송 사유 기재 |
| 협조 | 불필요 | 단일 기관 처리 사안 |
| 거부 여부 | 거부 아님 (이송) | 구제절차 통지 대상 아님 — 이송 기관·사유·향후 처리를 안내 |
| 유의점 | 이송 기관, 이송 사유, 향후 처리 안내를 답변에 포함 | |

### 인용 검증표 (내부)

| 법령·조문 | 출처(URL 또는 문서 식별정보) | 적용 버전(시행일) | 적용 기준일·선택 이유 | 확인 방법 | 확인일 | 상태 | 사안 적용 판단 |
|---|---|---|---|---|---|---|---|
| 민원 처리에 관한 법률 제16조제1항 | 국가법령정보센터, MST 239293 | 2022-07-12 | 이송일 — 발송 때 이행하는 절차 | 도구: `get_law_text` | 2026-10-25 | ✅ 검증 | 적용: 도로 시설물 설치는 도로 관리청인 ○○시 소관으로 판단 (가상값) |

조문 실존·적용 버전·확인일 칸은 스킬 작성 때(2026-10-25) 실제로 조회한 값이다. 이 법률은 2026-12-03 시행예정 개정(타법개정)이 있으나 제16조 문언은 같음을 같은 날 확인했다. 실제 답변에서는 발송 시점에 다시 조회한다. 사안 적용 판단 칸은 가상 사안에 대한 판단이다.

### 발송본 예시 (가상값 — 내부 표의 확인 완료를 가정)

귀하께서 요청하신 교육원 인근 도로의 과속방지턱 설치에 대하여 다음과 같이 안내드립니다.

검토 결과, 도로 안전 시설물의 설치는 도로 관리청인 ○○시(군·구)의 소관 사무에 해당하여, 「민원 처리에 관한 법률」 제16조에 따라 귀하의 민원을 ○○시(군·구)로 이송하였음을 알려드립니다.

이송된 민원은 해당 기관에서 검토 후 처리 결과를 귀하께 직접 안내할 예정입니다.

우리 기관도 학생 통학 안전에 관한 사항을 중요하게 인식하고 있으며, 해당 기관의 검토 과정에서 협조가 필요한 경우 적극 협력하겠습니다.

추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

## 사례 4: 전제 확인형 민원 (일반민원)

### 민원 요지

- 민원 유형: 일반민원 — 질의민원 (전제 확인형 — 민원인이 전제를 제시하고 각각의 확인을 요청하는 구조) (가상값)
- 신청 취지: 체험학습 프로그램 취소 시 참가비 환불 기준 확인
- 요구사항: 전액 환불 (전제 3의 취지)
- 민원인이 제시한 전제:
  - 전제 1 (법규): "운영 규정상 개인 사유 취소도 7일 전 통보 시 전액 환불로 이해됩니다."
  - 전제 2 (사실): "본인은 7일 전에 취소를 통보한 것으로 이해됩니다."
  - 전제 3 (포섭): "따라서 전액 환불 대상으로 이해됩니다. 이 이해가 맞는지 확인 요청드립니다. 다르다면 그 근거를 안내하여 주시기 바랍니다."

### 가상 규정 (이 예시 전용 — 실제 기관의 환불 정책이 아님)

「○○교육원 체험학습 운영 규정」 제○조(환불)

- 행사일 7일 전까지(7일 전 당일 포함) 취소 통보: 참가비 전액 환불
- 행사일 6일 전부터 3일 전까지 취소 통보: 참가비의 50% 환불
- 행사일 2일 전부터 행사 당일까지 취소 통보: 환불하지 않음
- 일수는 행사일을 빼고 거꾸로 센다(행사 전날 = 1일 전). 통보일은 접수 시스템의 접수일로 본다.

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 프로그램 운영 부서 |
| 전제 분해 | 전제 1=법규, 전제 2=사실, 전제 3=포섭 | 전제마다 인정·부정·유보 명시 |
| 전제 1 | 인정 (단서 조항 함께 안내) | 가상 규정 확인 |
| 전제 2 | 부정 — 시스템 접수 기록상 행사 5일 전 통보 | 접수 일시 확인 완료 |
| 전제 3 | 부정 — 전액 환불 대상 아님, 규정상 50% 환불 대상 (요구는 일부 수용) | 요건-사실 연결 제시 |
| 경계일 대조 | 7일 전 → 전액, 6일 전 → 50%, 3일 전 → 50%, 2일 전 → 환불 없음 | 구간이 겹치거나 비지 않음 |
| 거부 여부·구제절차 | 일부 거부 — 확인 요청 형식이지만 전액 환불 조치를 구하는 취지이므로 50%만 수용하면 거부에 해당 → 거부 이유와 구제절차 통지 | 다툴 여지: 환불액이라는 권리 변동 → 담당자·법무 검토 결과, 운영 규정에 따른 참가비 정산으로 처분성이 없는 것으로 판단 (가상값). 자료 제출 후 재검토 경로 안내. 재검토 접수 부서 ○○부서 확인 (가상값) |
| 유의점 | 세 전제 모두에 명시적으로 답변, 생략 금지 | 재검토 경로 안내 포함 |

### 질문별 대응표 (내부)

| 번호 | 요구·질의 항목 | 처리 | 대응 답변 문단 |
|---|---|---|---|
| 1 | 전제 1: 7일 전 통보 시 전액 환불 기준 | 인정 (단서 조항 함께 안내) | 첫째 문단 |
| 2 | 전제 2: 7일 전에 통보했는지 | 부정 (접수 기록상 5일 전) | 둘째 문단 |
| 3 | 전제 3: 전액 환불 대상인지, 다르면 그 근거 | 부정 (전액 환불 대상 아님 — 50% 환불 구간 해당, 요건-사실 연결 제시) | 셋째 문단, 재검토 경로는 그다음 재검토 안내 문단 |

### 발송본 예시 (가상값 — 내부 표의 확인 완료를 가정)

귀하께서 문의하신 체험학습 프로그램 참가비 환불 기준에 대하여, 문의하신 세 가지 사항 순서대로 안내드립니다.

첫째, 환불 기준에 대한 이해는 말씀하신 내용과 같습니다. 「○○교육원 체험학습 운영 규정」 제○조에 따라 개인 사유로 취소하는 경우에도 행사 7일 전까지(7일 전 당일 포함) 통보하시면 참가비 전액이 환불됩니다. 다만 같은 조에서 행사 6일 전부터 3일 전까지 통보한 경우에는 참가비의 50%를 환불하도록 정하고 있음을 함께 안내드립니다.

둘째, 통보 시점은 확인 결과 말씀하신 내용과 다릅니다. 우리 기관 접수 시스템상 귀하의 취소 신청은 2026년 ○월 ○일 접수되어, 행사일(2026년 ○월 ○일) 기준 5일 전에 해당합니다.

셋째, 이에 따라 귀하의 경우 전액 환불 대상에는 해당하지 않으며, 같은 규정 제○조에 따른 50% 환불 대상에 해당합니다. 환불액 ○○○원은 신청하신 계좌로 ○일 이내 입금될 예정입니다.

접수 시점 확인에 이의가 있으시면 통보 사실을 확인할 수 있는 자료(통화 기록, 문자 등)를 ○○부서로 제출하여 주시기 바랍니다. 확인 후 재검토하겠습니다.

추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

### 사례 4 참고

- 전제 확인형 민원은 질문 순서를 유지하며 전제마다 인정("이해는 말씀하신 내용과 같습니다"), 부정("확인 결과 다릅니다" + 근거), 판단("~에 해당합니다" + 요건-사실 연결)을 명시한다.
- 부정하는 전제는 반드시 확인된 근거(시스템 기록)를 함께 제시하고, 민원인이 반박 자료를 제출할 경로를 열어 둔다.
- 어느 전제도 생략하지 않는다. 생략된 질문은 무응답으로 기록되어 재민원·고충민원의 근거가 된다.
- 일부 거부이므로 구제절차를 함께 안내한다. 이 사례는 처분성이 없는 정산이라는 가상 검토 결과를 전제로 하므로 이의신청·행정심판 문구 대신 자료 제출 후 재검토 경로를 안내했다. 공공기관의 참가비 환불 결정처럼 처분성을 다툴 여지가 있으면 담당자·법무 검토로 정한다.
- 환불 구간은 경계일이 겹치거나 비지 않게 나눈다(7일 전 = 전액, 6일 전 = 50%). 실제 규정을 인용할 때도 "○일 전까지"와 "○일 전부터"가 같은 날을 함께 포함하지 않는지, 일수를 세는 방법이 정해져 있는지 확인하고, 불명확하면 `[확인 필요: 경계일 해석]`으로 남긴다.
