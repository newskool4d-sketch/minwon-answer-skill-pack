# 완성 답변 골든 예시

가상 사안 기반의 완성 예시 4건이다. 문체, 결론 우선 구조, 내부 검토표와 대민 발송본의 분리 방식을 참고용으로 보여준다. 실제 기관명, 인명, 사건은 모두 허구이며 개인정보를 포함하지 않는다.

---

## 사례 1: 수용 가능 (일반민원)

### 민원 요지

- 민원 유형: 일반민원
- 신청 취지: 교육원 체험학습 프로그램 신청 결과 안내 문자가 오지 않아 신청 처리 여부 확인을 요청
- 요구사항: 신청 처리 상태 확인 및 안내 절차 개선

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 프로그램 운영 부서 |
| 이송/다부처/협조 | 불필요 | 단일 부서 처리 |
| 처리기간 | 접수일부터 7일 (제도·절차 질의 성격) | 시스템 기한 확인 완료 |
| 법령근거 | 불필요 (사실 확인·안내 사안) | |
| 개인정보 | 신청자 본인 확인 후 본인 신청 건만 안내 | 제3자 정보 미포함 |

### 대민 발송본

귀하께서 신청하신 체험학습 프로그램의 처리 상태 확인을 요청하신 민원에 대하여 다음과 같이 안내드립니다.

확인 결과, 귀하의 신청은 정상적으로 접수되어 참가 확정 처리되었습니다. 다만 안내 문자 발송 과정에서 시스템 오류로 일부 신청자에게 문자가 발송되지 않은 사실을 확인하였습니다.

이에 우리 기관은 미발송 대상자에게 안내 문자를 재발송하였으며, 동일한 사례가 재발하지 않도록 발송 결과 확인 절차를 보완하였습니다.

불편을 드려 죄송하며, 추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

---

## 사례 2: 수용 곤란 (일반민원)

### 민원 요지

- 민원 유형: 일반민원
- 신청 취지: 교육원 시설(강당)을 외부 사적 행사 용도로 대관 요청
- 요구사항: 주말 사적 행사 목적 대관 승인

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 시설 관리 부서 |
| 법령근거 | 시설 사용 관련 조례·내부 규정 확인 완료 | 사용 허가 범위: 교육 목적 |
| 개인정보 | 미포함 | |
| 유의점 | 불가 사유를 규정 근거 중심으로 설명, 대안 안내 포함 | |

### 대민 발송본

귀하께서 요청하신 우리 기관 강당 대관에 대하여 다음과 같이 안내드립니다.

검토 결과, 요청하신 사적 행사 목적의 대관은 승인이 어려움을 알려드립니다.

우리 기관 시설은 관련 규정에 따라 교육 목적의 행사 및 공공 목적 활동에 한하여 사용 허가가 가능하며, 사적 행사는 사용 허가 대상에 포함되지 않습니다.

다만, 교육 목적 행사로 대관을 희망하시는 경우에는 사용 신청서를 행사 ○일 전까지 제출하시면 심사 후 안내드리겠습니다.

자세한 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 문의하여 주시기 바랍니다.

---

## 사례 3: 이송 (타 기관 소관)

### 민원 요지

- 민원 유형: 일반민원
- 신청 취지: 교육원 인근 도로의 통학 안전 시설(과속방지턱) 설치 요청
- 요구사항: 과속방지턱 설치

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 타 기관 소관 (도로 관리청) | 도로 시설물 설치 권한 없음 |
| 이송 필요 | 필요 — 관할 지방자치단체로 이송 | 이송 사유 기재 |
| 협조 | 불필요 | 단일 기관 처리 사안 |
| 유의점 | 이송 기관, 이송 사유, 향후 처리 안내를 답변에 포함 | |

### 대민 발송본

귀하께서 요청하신 교육원 인근 도로의 과속방지턱 설치에 대하여 다음과 같이 안내드립니다.

검토 결과, 도로 안전 시설물의 설치는 도로 관리청인 ○○시(군·구)의 소관 사무에 해당하여, 「민원 처리에 관한 법률」 제16조에 따라 귀하의 민원을 ○○시(군·구)로 이송하였음을 알려드립니다.

이송된 민원은 해당 기관에서 검토 후 처리 결과를 귀하께 직접 안내할 예정입니다.

우리 기관도 학생 통학 안전에 관한 사항을 중요하게 인식하고 있으며, 해당 기관의 검토 과정에서 협조가 필요한 경우 적극 협력하겠습니다.

추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

## 사례 4: 전제 확인형 민원 (일반민원)

### 민원 요지

- 민원 유형: 일반민원 (전제 확인형 — 민원인이 전제를 제시하고 각각의 확인을 요청하는 구조)
- 신청 취지: 체험학습 프로그램 취소 시 참가비 환불 기준 확인
- 민원인이 제시한 전제:
  - 전제 1 (법규): "운영 규정상 개인 사유 취소도 7일 전 통보 시 전액 환불로 이해됩니다."
  - 전제 2 (사실): "본인은 7일 전에 취소를 통보한 것으로 이해됩니다."
  - 전제 3 (포섭): "따라서 전액 환불 대상으로 이해됩니다. 이 이해가 맞는지 확인 요청드립니다. 다르다면 그 근거를 안내하여 주시기 바랍니다."

### 처리 판단 (내부)

| 점검 항목 | 판단 | 비고 |
|---|---|---|
| 소관 여부 | 우리 기관 소관 | 프로그램 운영 부서 |
| 전제 분해 | 전제 1=법규, 전제 2=사실, 전제 3=포섭 | 전제마다 인정·부정·유보 명시 |
| 전제 1 | 인정 (단서 조항 함께 안내) | 규정 검증 완료 |
| 전제 2 | 부정 — 시스템 접수 기록상 행사 5일 전 통보 | 접수 일시 확인 완료 |
| 전제 3 | 일부 수용 — 규정상 50% 환불 대상 | 요건-사실 연결 제시 |
| 유의점 | 세 전제 모두에 명시적으로 답변, 생략 금지 | 이의 절차 안내 포함 |

### 인용 검증표 (내부)

| 법령·조문 | 시행일자 | 상태 | 확인일 |
|---|---|---|---|
| ○○교육원 체험학습 운영 규정 제○조(환불) | 20XX-XX-XX | 행정규칙 수기 | 2026-XX-XX |

### 대민 발송본

귀하께서 문의하신 체험학습 프로그램 참가비 환불 기준에 대하여, 문의하신 세 가지 사항 순서대로 안내드립니다.

첫째, 환불 기준에 대한 이해는 말씀하신 내용과 같습니다. 「○○교육원 체험학습 운영 규정」 제○조에 따라 개인 사유로 취소하는 경우에도 행사 7일 전까지 통보하시면 참가비 전액이 환불됩니다. 다만 같은 조에서 행사 7일 전부터 3일 전까지 통보한 경우에는 참가비의 50%를 환불하도록 정하고 있음을 함께 안내드립니다.

둘째, 통보 시점은 확인 결과 말씀하신 내용과 다릅니다. 우리 기관 접수 시스템상 귀하의 취소 신청은 2026년 ○월 ○일 접수되어, 행사일(2026년 ○월 ○일) 기준 5일 전에 해당합니다.

셋째, 이에 따라 귀하의 경우 전액 환불 대상에는 해당하지 않으며, 같은 규정 제○조에 따른 50% 환불 대상에 해당합니다. 환불액 ○○○원은 신청하신 계좌로 ○일 이내 입금될 예정입니다.

접수 시점 확인에 이의가 있으시면 통보 사실을 확인할 수 있는 자료(통화 기록, 문자 등)를 ○○부서로 제출하여 주시기 바랍니다. 확인 후 재검토하겠습니다.

추가 문의 사항은 ○○부서(전화 ○○○-○○○-○○○○)로 연락하여 주시기 바랍니다.

### 사례 4 참고

- 전제 확인형 민원은 질문 순서를 유지하며 전제마다 인정("이해는 말씀하신 내용과 같습니다"), 부정("확인 결과 다릅니다" + 근거), 판단("~에 해당합니다" + 요건-사실 연결)을 명시한다.
- 부정하는 전제는 반드시 확인된 근거(시스템 기록)를 함께 제시하고, 민원인이 반박 자료를 제출할 경로를 열어 둔다.
- 어느 전제도 생략하지 않는다. 생략된 질문은 무응답으로 기록되어 재민원·고충민원의 근거가 된다.

## 예시 사용 시 유의

- 위 예시는 문체와 구조의 기준이며, 실제 답변에서는 사안별 법령·규정·시스템 기한을 반드시 확인한다.
- 발송본에는 `[확인 필요]` 표시, 내부 판단 메모, 점검 표를 포함하지 않는다.
- 이송 안내 시 인용한 조문(법 제16조)은 발송 전 현행 조문 여부를 확인한다.
