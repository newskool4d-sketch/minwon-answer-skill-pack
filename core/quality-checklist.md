# 최종 검토 체크리스트

항목 등급: **[차단]** = 미해소 시 발송 불가, **[권고]** = 품질 향상 항목 (가능하면 해소 후 발송).

## 내부 검토

- [ ] [차단] 민원 유형을 분류했는가?
- [ ] [차단] 소관 기관·부서를 확인했는가?
- [ ] [차단] 이송, 다부처, 협조, 재지정 필요 여부를 판단했는가?
- [ ] [차단] 처리기한과 연장 여부를 확인했는가?
- [ ] [차단] 관련 법령, 지침, 내부 기준을 확인했는가?
- [ ] [차단] 개인정보, 제3자 정보, 민감정보, 비공개 정보가 제거되었는가?
- [ ] [권고] 기존 답변이나 반복 민원 이력을 확인했는가?
- [ ] [권고] 보완요청 또는 추가자료 요청 필요성을 검토했는가?
- [ ] [권고] 사후관리 또는 추가답변 가능성을 확인했는가?

## 대민 답변 품질

- [ ] [차단] 민원 요지가 정확히 요약되었는가?
- [ ] [차단] 불가 또는 제한 사유가 근거와 함께 설명되었는가?
- [ ] [차단] 발송 전 `[확인 필요: 항목]` 표시가 모두 해소되었는가?
- [ ] [권고] 결론이 앞부분에 제시되었는가?
- [ ] [권고] 민원인이 다음에 무엇을 할 수 있는지 안내했는가?
- [ ] [권고] 불필요한 내부 용어, 화면명, 권한명이 제거되었는가?
- [ ] [권고] 공격적·방어적·단정적 표현이 없는가?
