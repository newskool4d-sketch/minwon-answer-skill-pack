# 처리기간, 연장, 사후관리

## 처리기간 확인

답변 전 다음 항목을 확인한다.

- 접수일
- 처리기한
- 민원 유형별 기본 처리기간
- 기관별 별도 분류 또는 내부권고기한
- 기간연장 가능 여부
- 보완요청으로 인한 기간 변화
- 의견조회 또는 협조요청으로 인한 기간 변화

운영관리 매뉴얼 분석상 일반민원, 고충민원, 개별법령, 일반질의, 법령질의, 제도개선건의, 민원이의신청 등은 기본 처리기간과 내부권고기한 설정이 관리될 수 있다. 실제 답변에서는 시스템 또는 최신 규정의 현재 설정을 확인한다.

## 법정 처리기간 기준표

「민원 처리에 관한 법률」 및 같은 법 시행령 기준 (확인일: 2026-06-11, 출처: 국가법령정보센터·생활법령정보). 초안 작성 시 출발점으로만 사용하고, **실제 기한은 반드시 시스템 표시 기한과 현행 조문으로 확인한다.** 법령 개정 가능성이 있으므로 불일치 시 현행 조문이 우선한다.

| 민원 유형 | 법정 처리기간 | 근거 |
|---|---|---|
| 법정민원 | 관계 법령 등에서 정한 기간 | 법 제17조 |
| 질의민원 (법령 해석·설명) | 14일 이내 | 시행령 제14조 |
| 질의민원 (제도·절차 설명) | 7일 이내 | 시행령 제14조 |
| 건의민원 | 14일 이내 | 시행령 제15조 |
| 기타민원 | 즉시 (기관 특성에 따라 달리 정할 수 있음) | 시행령 제16조 |
| 고충민원 | 7일 이내 (실지조사 필요 시 그 기간 추가 가능) | 시행령 제17조 |

처리기간 계산 (법 제19조):

- 5일 이하: 시간 단위 계산 (1일 = 8근무시간), 공휴일·토요일 제외
- 6일 이상: 일 단위 계산, 첫날 산입, 공휴일·토요일 제외

연장(시행령 제21조): 부득이한 사유가 있으면 처리기간의 범위에서 연장할 수 있고, 재연장 등 세부 요건은 현행 조문을 확인한다. 연장 시 민원인 통지 여부를 함께 점검한다.

## 기간연장

기간연장이 필요한 경우 다음을 명확히 한다.

- 연장 사유
- 연장되는 기한
- 추가 확인이 필요한 기관 또는 자료
- 민원인 안내 여부

제안 업무에서 의견조회 등록 시 처리기간이 자동 연장되는 사례가 있으며, 내용보완 요청 시 지정한 날짜만큼 기간이 연장될 수 있다. 실제 적용은 시스템 설정과 해당 업무 유형 기준을 확인한다.

## 보완요청

보완요청은 내용, 증빙, 요건이 불충분한 경우 사용한다.

보완요청 답변에는 다음을 포함한다.

- 보완이 필요한 항목
- 제출 방법
- 제출 기한
- 미제출 시 처리 방향
- 담당자 문의처

## 사후관리

사후관리는 처리 완료 후 이행 확인 또는 후속 조치가 필요한 경우 검토한다.

고충민원에서는 다음 결과가 사후관리카드 자동 생성 대상이 될 수 있다.

- 시정권고
- 의견표명
- 제도개선권고
- 제도개선의견표명
- 조정해결

답변 초안에는 대민 안내와 내부 사후관리 메모를 구분한다.

## 추가답변

제안 및 예산낭비신고 등에서는 처리 완료 후 만족도, 한마디 더, 불만족 사유에 따라 추가답변이 필요할 수 있다.

- 추가답변 가능 회차를 확인한다.
- 기존 답변과 충돌하지 않도록 작성한다.
- 새 조치가 없는 경우에도 검토 결과와 한계를 명확히 설명한다.
