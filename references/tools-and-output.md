# 도구 사용 및 산출 규칙

## 법령검토

법령 근거가 필요한 답변은 `korean-law-mcp`를 우선 사용한다. 인용 조문의 검증 절차, 상태 태그, 인용 검증표 양식, 실패 모드 처리는 `references/citation-verification.md`를 단일 출처로 따른다.

확인할 항목:

- 현행 조문
- 시행일
- 위임 규정
- 관련 고시, 훈령, 예규
- 교육청 조례 또는 규칙 필요 여부

법령 해석이 불확실하면 `공식 해석 또는 소관 부서 확인 필요`로 표시한다.

## 검색

최신 자료가 필요한 경우 `insane-search`를 사용한다.

검색이 필요한 예:

- 최신 교육부 또는 교육청 공지
- 최근 법령 개정
- 국민권익위원회 안내
- 관련 판례, 유권해석, 보도자료

## 심층 연구

복합 쟁점, 비교 사례, 정책 배경이 필요한 경우 `deep-research`를 사용한다.

## 산출물

기본 산출물은 Markdown이다.

권장 파일명:

```text
YYYY-MM-DD_민원답변초안_주제.md
YYYY-MM-DD_민원검토표_주제.md
YYYY-MM-DD_민원답변_발송본.md
```

발송본은 Markdown 파일과 함께, 답변 시스템 입력란에 붙여넣을 수 있는 서식 없는 텍스트 블록으로도 제공한다. 국민신문고 등 답변 입력란은 Markdown 서식이 적용되지 않아 `#`, `**` 같은 기호가 그대로 노출된다. 제공 시 글자수(공백 포함)를 함께 보고하고, 입력란 상한이 확인된 시스템이면 상한 대비 여유를 표시한다.

## HWPX 변환

사용자가 HWPX를 요청하면 같은 폴더에 변환한다.

변환기 경로·우선순위·실행 명령·변환 후 확인 절차는 `tools/convert-output.md`를 단일 출처로 따른다. 변환 도구가 없거나 한글 COM 자동화가 불가하면 Markdown까지만 산출하고 사유를 알린다.

## 도구 부재 시 대체 절차

이 스킬팩은 Codex, Claude Code, Gemini CLI 공용이므로 위 도구가 없는 환경이 있을 수 있다.

| 도구 | 부재 시 대체 |
|---|---|
| `korean-law-mcp` | 국가법령정보센터(law.go.kr) 웹 검색으로 현행 조문 확인 후, 확인일과 출처 URL을 인용 검증표에 기록(상태: 행정규칙 수기 또는 재검증 권장). 확인 불가 시 ⚠️ 미검증 태그 — 발송 불가 |
| `insane-search` | 사용 가능한 일반 웹 검색 도구로 대체. 검색 불가 환경이면 `[확인 필요: 최신 자료]`로 표시 |
| `deep-research` | 일반 검색을 단계적으로 반복하되, 근거가 부족하면 단정하지 않고 `[확인 필요]` 처리 |
| HWPX 변환기 | Markdown까지만 산출하고 변환 불가 사유를 알림 |
