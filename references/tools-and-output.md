# 도구 사용 및 산출 규칙

## 법령검토

법령 근거가 필요한 답변은 `korean-law-mcp`를 우선 사용한다.

확인할 항목:

- 현행 조문
- 시행일
- 위임 규정
- 관련 고시, 훈령, 예규
- 교육청 조례 또는 규칙 필요 여부

법령 해석이 불확실하면 `공식 해석 또는 소관 부서 확인 필요`로 표시한다.

## 검색

최신 자료가 필요한 경우 `insane-search`를 사용한다.

검색이 필요한 예:

- 최신 교육부 또는 교육청 공지
- 최근 법령 개정
- 국민권익위원회 안내
- 관련 판례, 유권해석, 보도자료

## 심층 연구

복합 쟁점, 비교 사례, 정책 배경이 필요한 경우 `deep-research`를 사용한다.

## 산출물

기본 산출물은 Markdown이다.

권장 파일명:

```text
YYYY-MM-DD_민원답변초안_주제.md
YYYY-MM-DD_민원검토표_주제.md
YYYY-MM-DD_민원답변_발송본.md
```

## HWPX 변환

사용자가 HWPX를 요청하면 같은 폴더에 변환한다.

1. `md_to_hwpx_com.py`를 찾는다.
2. 없으면 `to_hwpx_com.py` 등 호환 변환기를 찾는다.
3. 변환 후 HWPX 파일 존재 여부와 파일 크기를 확인한다.
4. 변환 도구가 없거나 한글 COM 자동화가 불가하면 Markdown까지만 산출하고 사유를 알린다.

예상 명령:

```powershell
python md_to_hwpx_com.py "답변초안.md" -o "출력폴더"
```

호환 도구:

```powershell
python to_hwpx_com.py "답변초안.md" -o "출력폴더"
```
