# 인용 검증 프로토콜

답변에 인용하는 모든 법령·행정규칙·자치법규·판례는 발송 전 현행 데이터로 검증한다. 기억, 요약자료, 과거 답변 사례의 인용문을 그대로 옮기지 않는다. 잘못된 조문 인용은 답변 전체의 신뢰를 무너뜨리고, 재민원·고충민원·행정심판 단계에서 기관의 절차적 약점으로 남는다.

## 검증 절차 (korean-law-mcp)

인용할 조문마다 다음 순서로 확인한다.

1. `search_law` — 법령 존재 여부, 시행일자, 소관부처를 확인한다. 개정·제명변경·시행예정 여부를 함께 본다.
2. `get_law_text` — 조문 전문을 그대로 가져와 인용한다. 항·호 구조와 `<개정 …>` 표기를 유지한다. `<개정>` 일자가 참고자료보다 최신이면 참고자료가 아니라 현행 조문을 따른다.
3. `legal_analysis` (verify_citations 모드) — 초안 완성 후 인용 전체를 일괄 점검한다. 조문 존재 여부와 조문 제목 불일치(예: "제750조(계약해제)" 류 오류)를 잡는다.
4. 행정규칙(고시·훈령·예규·지침) — 서버에 전용 도구가 보이지 않으면 `discover_tools`로 사용 가능한 도구를 확인하고(`execute_tool` 경유 포함), 없으면 law.go.kr 행정규칙 검색으로 수기 검증한다.
5. 판례 — `search_decisions`, `get_decision_text`로 확인한다.
6. 조례·교육규칙 — 자치법규는 `ordinance_radar` 또는 law.go.kr 자치법규 검색으로 확인한다. 교육청 답변은 조례·교육규칙 근거가 잦으므로 생략하지 않는다.

인용 1건당 조회 1회를 원칙으로 하고, 확인한 시행일자와 확인일을 인용 검증표에 남긴다.

## 절차 조문도 동일하게 검증

처리기한, 이송 의무, 보완요청 요건, 이의신청 기간 등 절차 근거(「민원 처리에 관한 법률」, 행정절차법, 행정심판법, 정보공개법 등)를 답변에 명시할 때도 실체 조문과 동일하게 검증한다. "처리기한 14일" 같은 일반 사다리를 기억으로 적지 않는다 — 기한과 의무는 민원 유형, 기관 규칙, 처분 여부에 따라 달라진다. `references/deadlines-and-followup.md`의 기준표는 출발점일 뿐이며, 답변에 인용하는 순간 현행 조문 확인 대상이 된다.

## 인용 상태 태그

| 태그 | 의미 | 발송 가능 여부 |
|---|---|---|
| ✅ 검증 | 도구로 현행 조문 전문·시행일자 확인 완료 | 가능 |
| 재검증 권장 | 도구 조회 실패 후 수기 확인했으나 법령명·조번호 불일치 의심이 남음 | 담당자 재확인 후 가능 |
| 행정규칙 수기 | 고시·훈령·예규·조례를 law.go.kr에서 수기 확인 (확인일 기록) | 가능 |
| ⚠️ 미검증 | 어떤 방법으로도 확인하지 못함 | 발송 불가 — 확인 후 발송 |

검증에 실패한 인용이 침묵 인용이 되어서는 안 된다. 확인하지 못한 조문은 반드시 태그를 남기고, 발송본에서는 해당 문장을 빼거나 확인 후 넣는다.

## 인용 검증표 양식 (내부 검토표에 포함)

법령·규정을 인용한 답변은 내부 검토표에 다음 표를 포함한다.

| 법령·조문 | 시행일자 | 상태 | 확인일 |
|---|---|---|---|
| 민원 처리에 관한 법률 제16조 | 20XX-XX-XX | ✅ 검증 | 2026-XX-XX |
| ○○교육청 ○○ 조례 제○조 | 20XX-XX-XX | 행정규칙 수기 | 2026-XX-XX |

## 실패 모드별 처리

| 상황 | 처리 |
|---|---|
| korean-law-mcp 부재·오류 | law.go.kr에서 수기 확인하고 확인일·출처를 검증표에 기록. 그것도 불가하면 ⚠️ 미검증 태그 후 내부 확인 요청 |
| 조문 미발견 | 법령명·조번호를 재확인(`search_law` 재시도, 약칭·구법명 의심) → 수기 확인 → 그래도 불확실하면 재검증 권장 |
| 행정규칙·조례 미조회 | law.go.kr 행정규칙·자치법규 검색에서 수기 확인 → 행정규칙 수기 태그 |

## 용어 자기점검

- 소관부처는 조직 개편으로 바뀐다. `search_law`가 돌려주는 현재 소관부처를 기억보다 우선한다.
- 위임과 위탁은 법적으로 다르다(내부 위임 vs 외부 위탁, 결정 주체가 달라짐). 바꿔 쓰지 않는다.
- 유사 용어(허가·인가·승인·신고 등)는 조문이 실제 쓰는 용어를 그대로 쓴다.
